## 🛠️ Projects

### [ChainBeacon](https://github.com/cryptoumit/ChainBeacon)
**Blockchain intelligence assistant for customer support teams.**

A Chrome extension that identifies common blockchain addresses and transaction IDs across Bitcoin, Ethereum, XRP, TRON, and Solana, validates their formats locally, and helps support agents open the appropriate block explorer.

Built with TypeScript, React, and Vite.

### [Typadoo](https://github.com/cryptoumit/Typadoo)
**A local-first text expansion Chrome extension.**

A productivity tool for managing reusable text snippets, with search, favorites, and categories. Designed to keep user data local, without accounts, cloud sync, or telemetry. You give permissions only for websites needed, no global/system permissions needed.

Built with TypeScript, React, and Vite.

### [JSON & API Viewer](https://github.com/cryptoumit/json-viewer)
**A lightweight browser-based JSON and API utility.**

A tool for formatting and validating JSON, inspecting API responses, making API requests, with a built-in Unix timestamp converter(in case your JSON/API response has timestamps). Built with vanilla HTML, CSS, and JavaScript, with no backend or external dependencies.

[Live demo](https://cryptoumit.github.io/json-viewer/)

### [BIP39 – Solana Support](https://github.com/cryptoumit/bip39)
A fork of [Ian Coleman's BIP39 tool](https://github.com/iancoleman/bip39), Solana support added with non-standard derivation paths like Exodus.
